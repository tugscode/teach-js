# 🛠️ Variable Declarations (Хувьсагч зарлах)

> [!IMPORTANT] Үндсэн ойлголт
> 
> JavaScript-д хувьсагчийг ашиглахын тулд бид эхлээд түүнийг **үүсгэх** буюу **зарлах (declare)** ёстой. Үүний тулд бид `var`, `let`, эсвэл `const` гэсэн түлхүүр үгсийн аль нэгийг ашигладаг.

---

## 📊 Түлхүүр үгсийн харьцуулалт

|**Түлхүүр үг**|**Тайлал**|**Зөвлөмж**|
|---|---|---|
|**`var`**|Хуучин арга (ES6-аас өмнөх)|❌ Ашиглахаас зайлсхий|
|**`let`**|Утга нь өөрчлөгдөх хувьсагч|✅ Шаардлагатай үед ашигла|
|**`const`**|Тогтмол (өөрчлөгдөхгүй) утга|⭐️ Хамгийн түгээмэл ашигла|

---

## 🔍 Гурван төрлийн зарлалт

### 1. const (Constant)

Хамгийн аюулгүй, найдвартай арга. Хэрэв та тухайн хувьсагчийн утгыг дараа нь өөрчлөхгүй бол үүнийг ашиглана.

JavaScript

```
const birthYear = 1995;
// birthYear = 2000; // ❌ Алдаа заана: Утгыг нь өөрчилж болохгүй.
```

### 2. let (Block-scoped)

Хэрэв хувьсагчийн утга кодын явцад өөрчлөгдөх шаардлагатай бол үүнийг ашиглана.

JavaScript

```
let score = 10;
score = 15; // ✅ Боломжтой: Утга нь шинэчлэгдэнэ.
```

### 3. var (Legacy)

Функцын хүрээнд ажилладаг (Function-scoped). Орчин үеийн JS хөгжүүлэлтэд үүнийг бараг ашигладаггүй.

JavaScript

```
var name = "Бат";
```

---

## 💡 Багшийн зөвлөгөө

Суралцагчдадаа дараах "Алтан дүрэм"-ийг хэлж өгөөрэй:

1. Бүх хувьсагчаа эхлээд **`const`**-оор зарлаж үз.
    
2. Хэрэв утгыг нь заавал өөрчлөх шаардлага гарвал (жишээ нь: давталт доторх тоолуур) **`let`** болгож өөрчил.
    
3. **`var`**-ийг зүгээр л түүх гэж сана!
