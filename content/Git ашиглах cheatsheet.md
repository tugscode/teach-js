# 🖥️ Terminal & Git Basics (Үндсэн тушаалууд)

> [!ABSTRACT] Зорилго
> 
> График интерфэйс (хулгана) ашиглахгүйгээр файл системтэй харилцаж сурах болон кодынхоо хувилбарыг хянаж сурах.

---

## 📂 1. Linux/Unix Directory Commands (Файлтай ажиллах)

Терминал дээр хавтас болон файлтай харьцах үндсэн тушаалууд:

|**Тушаал**|**Тайлбар**|**Жишээ**|
|---|---|---|
|**`pwd`**|Одоо байгаа хаягийг харах (Print Working Directory)|`pwd`|
|**`ls`**|Доторх файл, хавтаснуудыг жагсаах|`ls` эсвэл `ls -a` (нууц файлыг харах)|
|**`cd`**|Хавтас руу орох / шилжих (Change Directory)|`cd Documents` эсвэл `cd ..` (буцах)|
|**`mkdir`**|Шинэ хавтас үүсгэх (Make Directory)|`mkdir js-lesson-1`|
|**`touch`**|Шинэ файл үүсгэх|`touch index.html`|
|**`rm`**|Файл устгах (Remove)|`rm style.css`|
|**`rm -rf`**|Хавтасыг доторхтой нь хамт устгах|`rm -rf old-folder`|
|**`clear`**|Терминалын дэлгэцийг цэвэрлэх|`clear`|

## 🌿 2. Git-ийн үндсэн үйлдлүүд (Version Control)

Git бол кодын "цаг хугацааны машин" юм. Кодонд гарсан өөрчлөлт бүрийг тэмдэглэж авдаг.

### 🔄 Өдөр тутмын Git Workflow:

1. **`git init`** - Төслийг Git-ээр хянаж эхлэх (Анх удаа л хийнэ).
    
2. **`git status`** - Ямар файл өөрчлөгдсөн байгааг шалгах.
    
3. **`git add <файл>`** - Өөрчлөлтийг "сагсанд" хийх (Staging area). Бүх файлыг нэмэх бол `git add .` ашиглана.
    
4. **`git commit -m "тайлбар"`** - Сагсанд хийсэн өөрчлөлтүүдээ баталгаажуулж "зураг" болгон хадгалах.
    
5. **`git log`** - Өмнө нь хийгдэж байсан бүх commit-уудын түүхийг харах.
    

### ☁️ GitHub-тай холбох:

1. **`git remote add origin <URL>`** - Өөрийн компьютер дээрх кодыг онлайн GitHub-тай холбох.
    
2. **`git push -u origin main`** - Өөрийн кодоо GitHub руу анх удаа илгээх.
    
3. **`git pull`** - GitHub дээрх өөрчлөлтийг өөрийн компьютер руу татаж авах.

## 🛠️ Дадлага даалгавар (Practice)

Оюутнуудаар дараах даалгаврыг терминал дээр хийлгээрэй:

1. `mkdir practice-day2` гэж хавтас үүсгэ.
    
2. `cd practice-day2` гэж хавтас руугаа ор.
    
3. `touch notes.txt` гэж файл үүсгэ.
    
4. `git init` хийж Git-ийг идэвхжүүл.
    
5. `git add notes.txt` хийж файлаа нэм.
    
6. `git commit -m "first file created"` гэж баталгаажуул.
    
7. `ls` хийж файлаа байгаа эсэхийг шалгаад, `rm notes.txt` гэж устга.
    
8. `git status` гэж бичээд юу болж байгааг ажигла.
