# 🔭 Variable Scopes (Хувьсагчийн хүрээ)

> [!ABSTRACT] Тодорхойлолт **Scope** буюу хүрээ нь хувьсагчийг кодын аль хэсгээс уншиж, ашиглаж болохыг тодорхойлдог "хязгаар" юм.

---

## 🌍 1. Global Scope (Глобал хүрээ)

Ямар нэгэн функц эсвэл блокын гадна зарлагдсан хувьсагч.

- **Хүртээмж:** Кодын хаанаас ч хандаж, өөрчилж болно.
    
- **Сөрөг тал:** Глобал хувьсагч хэт их байх нь кодонд алдаа гарах магадлалыг ихэсгэдэг (Global pollution).
    

## 📞 2. Function Scope (Функцийн хүрээ)

Зөвхөн тухайн функц дотор зарлагдсан хувьсагч.

- **Хүртээмж:** Зөвхөн тэр функц дотроо л ажиллана. Функцийн гаднаас хандах боломжгүй.
    

## 📦 3. Block Scope (Блокын хүрээ)

`let` болон `const`-оор зарлагдсан хувьсагчид хамааралтай. `{ }` хаалт дотор (жишээ нь: `if` нөхцөл, `for` loop) зарлагдсан бол зөвхөн тэр дотроо л хүчинтэй.

- **Анхаар:** `var` нь блок хүрээг үл тоомсорлодог тул блок дотор зарласан ч гаднаас нь хандаж болдог аюултай.
    

---

## 🌓 Local Scope (Локал хүрээ)

**Local scope** гэдэг нь ерөнхийдөө Функцийн хүрээ болон Блокын хүрээг хамтад нь нэрлэж буй хэлбэр юм. Энэ нь хувьсагч кодын зөвхөн тодорхой хэсэгт л амьдарна гэсэн үг.

---

## 🧱 4. Module Scope (Модуль хүрээ)

Кодыг олон файл болгон хувааж ажиллахад ашиглагдана. Модуль доторх хувьсагчид глобал хүрээг "бохирдуулахгүй" бөгөөд зөвхөн тухайн файл (модуль) дотроо л хүчинтэй байна.

---

## 📝 Жишээ код

JavaScript

```
let globalVar = "Би хаана ч харагдана";

function scopeTest() {
    let functionVar = "Би зөвхөн функц дотор харагдана";
    
    if (true) {
        let blockVar = "Би зөвхөн энэ IF дотор харагдана";
        const alsoBlock = "Би ч бас";
        var notBlock = "Би var учраас гадаа нь харагдаж чадна!";
    }
}
```

---

> [!TIP] Багшийн зөвлөгөө Суралцагчдад **"Хувьсагчийг аль болох бага хүрээнд (Block scope) байлгах нь сайн программистын шинж"** гэдгийг онцолж хэлээрэй. Энэ нь санамсаргүй алдаанаас сэргийлдэг.
