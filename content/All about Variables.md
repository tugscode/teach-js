## 💡 Багшийн санамж: Гол ялгаа

Суралцагчдад **let** болон **const**-ийн ялгааг маш сайн ойлгуулах хэрэгтэй.

> [!CHECK] Хэзээ алийг нь ашиглах вэ?
> 
> 1. Утга нь өөрчлөгдөхгүй бол: **`const`** (Тогтмол) - _Жишээ нь: Төрсөн он_
>     
> 2. Утга нь өөрчлөгдөх бол: **`let`** - _Жишээ нь: Тоглоомын оноо_
>     
> 3. Орчин үеийн JS-д **`var`**-ийг ашиглахаас аль болох татгалзаарай!
>     

---

## ✍️ Жишээ код

JavaScript

```
const name = "Бат"; // Өөрчлөх боломжгүй
let score = 0;     // Өөрчлөх боломжтой

score = score + 10;
console.log(name, "оноо:", score);
```
