# 🛠️ JavaScript хэрхэн ажиллуулах вэ? (How to run JS)

JavaScript-ийг ажиллуулах хэд хэдэн үндсэн арга байдаг. Та өөрийн хэрэгцээнд тохируулан дараах аргуудаас сонгоорой.

---

## 1. Вэб хөтөч дээр ажиллуулах (Browser)

Вэб хөтөч бол JavaScript-ийн "төрөлх гэр" юм.

### 🌐 HTML дотор оруулах

HTML файл дотор `<script>` таг ашиглан хоёр янзаар бичиж болно:

- **Дотоод код (Inline):** HTML файл дотроо шууд бичих.
    
- **Гадаад файл (External):** Тусдаа `.js` өргөтгөлтэй файл үүсгэж холбох.
    

HTML

```
<script src="script.js"></script>

<script>
  console.log("Сайн уу, Вэб!");
</script>
```

### 💻 Хөгжүүлэгчийн консол (Browser Console)

Ямар ч вэб хуудас дээр хулганы баруун товчийг дарж **Inspect** -> **Console** цэс рүү ороод JS кодыг шууд бичиж ажиллуулж болно. Энэ нь жижиг код туршихад хамгийн хурдан арга юм.

---

## 2. REPL болон Node.js орчин

Хэрэв та заавал вэб хөтөч нээлгүйгээр консол дээр код туршихыг хүсвэл **REPL** ашиглаж болно.

> [!INFO] REPL гэж юу вэ?
> 
> **REPL** (Read-Eval-Print Loop) нь таны оруулсан кодыг уншаад, ажиллуулж, үр дүнг нь шууд хэвлэж харуулдаг интерактив орчин юм. Node.js суулгасан бол терминал дээрээ `node` гэж бичээд шууд ашиглах боломжтой.

---

## ⚙️ Ажиллуулах аргуудын харьцуулалт

|**Арга**|**Хэзээ ашиглах вэ?**|**Давуу тал**|
|---|---|---|
|**Console**|Туршилт хийхэд|Хурдан, суулгах зүйлгүй|
|**Script tag**|Вэб сайт бүтээхэд|HTML-тэй шууд харилцана|
|**Node.js / REPL**|Сервер талын код бичихэд|Хөтөчөөс хамааралгүй|
