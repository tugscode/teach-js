# 🏗️ Hoisting (Өргөгдөх зарчим)

> [!ABSTRACT] Тодорхойлолт
> 
> **Hoisting** гэдэг нь JavaScript-ийн хөрвүүлэгч (interpreter) кодыг ажиллуулахаас өмнө **функц, хувьсагч болон классын зарлалтуудыг** тухайн хүрээнийх нь (scope) хамгийн дээр аваачиж буй мэт ажиллах процессыг хэлнэ.

---

## 🧐 Энэ нь яг яаж ажилладаг вэ?

Код бичих явцад та хувьсагчийг зарлахаас нь өмнө дуудаж ашиглах үед JavaScript алдаа заахын оронд "өргөж" гаргаж ирдэг. Гэхдээ `var`, `let`, `const` гурав дээр өөр өөрөөр илэрдэг.

### 1. `var` ба Hoisting

`var`-оор зарласан хувьсагч өргөгдөхдөө `undefined` утгатай болдог.

JavaScript

```
console.log(name); // Гаралт: undefined (Алдаа заахгүй!)
var name = "Бат";
```

### 2. `let` болон `const` ба Hoisting

Эдгээр нь мөн адил өргөгддөг боловч **Temporal Dead Zone (TDZ)** буюу "Түр зуурын үхэлд бүс"-д ордог. Зарлахаас нь өмнө хандах гэж оролдвол шууд алдаа заана.

JavaScript

```
console.log(age); // ❌ ReferenceError заана
let age = 25;
```

### 3. Functions (Функц) ба Hoisting

Функцийн зарлалт (Function Declaration) нь бүхэлдээ хамгийн дээр өргөгддөг. Тиймээс функцийг тодорхойлохоос өмнө дуудаж ажиллуулах бүрэн боломжтой.

JavaScript

```
sayHello(); // Гаралт: "Сайн уу!"

function sayHello() {
    console.log("Сайн уу!");
}
```

---

## ⚠️ Анхаарах зүйлс

|**Төрөл**|**Hoisting болох уу?**|**Үр дүн**|
|---|---|---|
|**var**|✅ Тийм|`undefined` утга авна.|
|**let / const**|✅ Тийм|Алдаа заана (TDZ-д байгаа тул).|
|**Function Declaration**|✅ Тийм|Шууд ажиллана.|
|**Function Expression**|❌ Үгүй|Хувьсагч зарласан мэт ажиллана.|
