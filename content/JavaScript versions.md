
# 🧬 JavaScript-ийн хувилбарууд (Versions)

> [!ABSTRACT] Стандартчилал
> 
> 1997 онд JavaScript нь **ECMA International** байгууллагаар батлагдсанаар албан ёсоор **ECMAScript** гэх нэршилтэй болсон. Энэ нь хэлний хөгжлийг нэгдсэн стандартад оруулж, бүх вэб хөтөч дээр ижил ажиллах нөхцөлийг бүрдүүлсэн юм.

---

## 🚀 Хувилбаруудын хувьсал

JavaScript нь цаг хугацааны явцад дараах гол үе шатуудыг дамжин хөгжсөн:

### 📑 Эртний үе (Legacy)

- **ES1, ES2, ES3**: Хэлний суурь тавигдсан үе.
    
- **ES5 (2009)**: Маш тогтвортой, удаан хугацаанд ашиглагдсан "сонгодог" хувилбар.
    

### ⚡ Шинэ эрин үе (The Modern Era)

- **ES6 (ECMAScript 2015)**: Энэ бол JavaScript-ийн түүхэн дэх **хамгийн том шинэчлэл** юм. Хэлийг илүү хүчирхэг, бичихэд хялбар болгох олон шинэ боломжуудыг (Arrow functions, Classes, Let/Const гэх мэт) нэмсэн.
    

---

## 📊 Хувилбаруудын харьцуулалт

|**Хувилбар**|**Гарсан он**|**Онцлох өөрчлөлт**|
|---|---|---|
|**ES1**|1997|Анхны албан ёсны стандарт.|
|**ES5**|2009|Strict mode, JSON дэмжлэг, Array methods.|
|**ES6**|2015|Classes, Modules, Promises, Arrow Functions.|
|**ESNext**|Жил бүр|Жил бүр бага багаар шинэчлэгддэг орчин үеийн JS.|

---

## 💡 Яагаад чухал вэ?

Вэб хөгжүүлэлтийн салбар зогсолтгүй өөрчлөгдөж байдаг. Эдгээр шинэчлэлтүүд нь:

1. Код бичих явцыг **хялбарчилдаг**.
    
2. Програмын **гүйцэтгэлийг (performance)** сайжруулдаг.
    
3. Томоохон төслүүд дээр ажиллахад илүү **зохион байгуулалттай** болгодог.
