
# 🟡 JavaScript

> [!INFO] Тодорхойлолт **JavaScript (JS)** бол HTML болон CSS-ийн хамт Вэб технологийн тулгуур багана болдог програмчлалын хэл юм. Энэ нь вэб хуудсыг зүгээр нэг статик контент байхаас гадна **амьд, интерактив** болгох үүргийг гүйцэтгэдэг.

---

## 🚀 JavaScript-ийн боломжууд

### 🌐 Вэб хөтөч дээр (Client-side)

Вэб сайт дээрх таны харж буй ихэнх хөдөлгөөнт үйлдлүүд JS дээр суурилдаг:

- 🖼️ Слайдер (Sliders) болон зурган галлерей
    
- 🔔 Сонордуулга (Alerts) болон Попап (Popups) цонх
    
- 🖱️ Товчлуур дарах үеийн хариу үйлдэл
    
- 🔄 Хуудсыг дахин ачаалахгүйгээр мэдээлэл шинэчлэх
    

### 💻 Бусад орчинд (Universal JS)

JS зөвхөн вэбээр хязгаарлагдахаа больсон:

- **Node.js**: Сервер талын код бичих (Backend)
    
- **Electron**: Компьютерт зориулсан апп бүтээх (Desktop apps)
    
- **React Native**: Гар утасны аппликейшн хөгжүүлэх (Mobile apps)
