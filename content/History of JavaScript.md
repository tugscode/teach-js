
# 📜 JavaScript-ийн түүх (History)

> [!QUOTE] Товчхондоо
> 
> JavaScript нь 1995 онд Netscape-ийн **Брендан Эйх (Brendan Eich)**-ийн гараар ердөө 10-хан хоногийн дотор бүтээгдсэн түүхтэй.

---

## ⏳ Нэршил болон Хөгжлийн явц

JavaScript-ийн нэр өөрчлөгдөж ирсэн түүх нэлээд сонирхолтой:

1. **Mocha** ☕
    
    - Анх бүтээгчийнх нь өгсөн нэр.
        
2. **LiveScript** ⚡
    
    - Mocha-г удалгүй LiveScript болгож өөрчилсөн.
        
3. **JavaScript** 🚀 (1996)
    
    - Netscape 2.0 хувилбартай хамт албан ёсоор "JavaScript" нэрээр гарсан.
        

> [!WARNING] Чухал анхааруулга
> 
> Тухайн үед **Java** хэл маш алдартай байсан тул түүний нэр хүнд дээр "дөрөөлөх" (capitalizing) зорилгоор JavaScript гэж нэрлэсэн. Бодит байдал дээр **Java болон JavaScript нь хоорондоо ямар ч холбоогүй** хэлүүд юм.

---

## 📅 Түүхэн цаг хугацааны шугам

|**Он**|**Үйл явдал**|**Тайлбар**|
|---|---|---|
|**1995**|Үүсэл|Брендан Эйх Netscape-д зориулж анхны хувилбарыг гаргав.|
|**1996**|Ребрэндинг|Java-ийн нэр хүндийг ашиглан нэрээ албан ёсоор өөрчлөв.|
|**1997**|Стандартчилал|ECMA International-д бүртгүүлж, стандарт хэл болох замдаа орсон.|
